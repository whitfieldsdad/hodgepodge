# Python

## Usage

To install the package along with any dependencies:

```bash
poetry install
```

To update the dependencies:

```bash
poetry update
```

To run the tests:

```bash
poetry run pytest
```

To enter a `virtualenv`<sub>1</sub>:

```bash
$(poetry env activate)
```

<sub>1. Entering a `virtualenv` consists of entering a new shell where all of your project's dependencies are installed.</sub>
